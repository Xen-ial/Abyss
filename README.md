# Abyss

Abyss is a theme for BeefIDE. Drop the `/abyss.toml` in your themes folder then point BeefIDE towards it.  
Original GIMP xcf files can be found under `/gimp-xcf` feel free to open them up and modify them.  

Enjoy!  

## DarkUI Replacements

[Linux]
In order to use them go to your Beef/BeefIDE installation location. then go under bin and images `/BeefLang/bin/images` back up both `/DarkUI.psd` and `/DarkUI_4.psd` then replace them with the psd's in this repo.  

Use wine to run `ImgCreate.exe` it can be found under `/BeefLang/bin/images`.  

[Windows]
Rename `/DarkUI.psd` and `/DarkUI_4.psd` to `/UI.psd` and `/UI_4.psd` and place them next to the `/abyss.toml` then load abyss inside your IDE and it should automatically generate the new images.  

[Docs]
For more information on how beef IDE themes work visit the beef website: [beef-docs](www.beeflang.org/docs/ide/themes/)
